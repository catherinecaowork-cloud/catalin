## Context

见 [proposal.md](proposal.md)。P1.1 确定性清洗与现有 P1.2 Compiler（只润色 label/value、禁止改 action/target）已经落地。回放侧已有 `choose_mode` 与「面板里有啥选啥」。缺的是录制中把页面认成字段/组件模型，并让模型**编写**脚本。

红线不变：控制面不装浏览器；执行器不连库、不调模型；已保存流程的日常回放零模型调用。观察者只在录制会话与结束后的编写阶段用网关。

## Goals / Non-Goals

**Goals:**

- 录制中持续上报脱敏页面快照，控制台能看到「已认识」的字段/组件清单
- 停止录制后，观察者一次编写：页面模型 + DSL；选择类步骤默认任选合法项
- 编写产物走现有编译验证状态机（DSL + 无头回放）；失败降级到样例轨迹 / Compiler 润色
- 模型挂在录制与保存后的流程上，同站点下次录制可当输入

**Non-Goals:**

- 录制过程中每点一下就调一次模型改脚本
- 全站对象库管理 UI、跨环境自动对齐组件
- 引入 browser-use 或让 Worker 调模型
- 替换 Playwright 录制器；样例轨迹仍要采集

## Decisions

### D1：观察采集在执行器，认识与编写在控制面

**为什么**：与 Compiler 相同。密钥、状态机、控制台都在控制面；Worker 只上报自包含快照。

**备选**：Worker 内边录边调模型——密钥分散、难持久化、开窗机断网即停。

### D2：录制中只做结构化观察，模型调用放在结束编写

**为什么**：用户要的是「录的时候在观察、停了再写脚本」。第一版把「观察」做成高信号快照（导航完成、弹层开合、表单节点出现），用现有 `__atpDescribe` / 表单 label / widget 启发式抽出字段清单，控制台即时能看。LLM 只在结束时吃：意图 + 全部快照 + 样例轨迹 → 页面模型 + DSL。避免边点边烧 token，也避免半成品脚本和人手抢焦点。

**备选**：每个快照都增量调模型。第一版不做；快照协议留足字段，以后可加节流增量。

### D3：快照是字段库存，不是 HTML

每条观察包含：url、层（page/modal/drawer + 名称）、可见字段（label、控件种类、候选定位摘要、是否必填）、当前打开的选择面板种类。条数与单条体积封顶，密码类值脱敏，与 `compiler_context` 同一套规则。

**备选**：整页 innerHTML 或全页截图。体积大、噪声大；视觉默认关，与现网关开关一致。

### D4：样例轨迹与观察者脚本分栏保存

`Run.summary`（或录制 compilation 记录）同时存 `sample_steps` 与 `observer_steps`。验证回放跑 `observer_steps`。控制台确认页默认展示观察者脚本，可切换看样例。降级时 `observer_steps` 为空，保存走样例。

### D5：选择类默认写入已有 `choose_mode`，不新造动作

观察者输出必须落在现有 DSL。下拉 / 面板：`choose` + `search_or_first` 或回放已实现的任选。唯一性输入：`{{unique:key}}`。禁止把「Gucci」「155」写成回归契约，除非意图明确要求该主数据。

### D6：观察者开启时放宽 Compiler 契约，关闭时不变

编写轮次允许改 action/target/顺序（相对样例）。仅润色轮次仍禁止改骨架。验证失败轮次把失败摘要 + 当前页面模型打回观察者重写，上限与 Compiler 相同（3 轮），然后降级。

### D7：页面模型跟流程走，站点级只读复用

表或 JSON 列：`site_id` + `flow_id`（保存后）+ 录制 id。同站点新录制把已有流程的模型条目一并送进编写输入。第一版不做独立「元素库」页面。

## Risks / Trade-offs

| 风险 | 缓解 |
| --- | --- |
| 结束才调模型，录制中「认识」偏清单化 | 快照用确定性控件识别，控制台先列字段；编写阶段再标「怎么用」 |
| 观察者写错步骤 | DSL 校验 + 无头验证回放；3 轮后降级样例 |
| 任选把必填选空 | 无选项且必填则失败；非必填才 skip（沿用现回放） |
| 快照过多 | 按导航/弹层去重；总数封顶 |
| 与现 Compiler 双路径混淆 | 确认页标明「观察者脚本 / 样例 / 润色稿」；开关默认开观察者，失败自动降级 |

## Migration Plan

1. 部署控制面与执行器；模型网关沿用现有 `ANTHROPIC_*` / 控制台 AI 配置
2. 旧流程无页面模型，回放行为不变
3. 新录制默认走观察者编写；无网关时行为与现在「确定性步骤 + 可选润色」一致
4. 回滚：关闭观察者开关即回到 Compiler 契约
