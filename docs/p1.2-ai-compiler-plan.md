# P1.2 实施计划：AI 编译（润色层）

这是一份交接文档。P1.1 的确定性录制-回放闭环已经成立；本文的 P1.2 在其上增加
**Compiler 层**：语义 label、断言推断、参数化，以及「编译产物必须自证可回放」。
模型**不能**改点击骨架，录制轨迹仍几乎等于脚本。

若要把录制当成一次样例、由 **AI 观察者认识页面再编写脚本**（下拉任选、不写死某次选项），见第一版：
`docs/p1.2-ai-observer-plan.md`（OpenSpec `ai-observer-p1-2`）。

上层设计见 `docs/p1-record-heal-chat.md` §1.3–1.4。本文只讲 Compiler 怎么实现与验收。

## 0. 三条红线（继承 P1.1）

| 红线 | 后果 |
| --- | --- |
| **控制面不装浏览器** | AI 编译与验证编排都在控制面；浏览器回放仍派给执行器 |
| **执行器不连数据库** | 验证 run 的 job 必须自包含 |
| **日常回归零模型调用** | 只有录制结束后的编译阶段调模型；已保存流程回放不再调 |

### 1.2 录制上下文（脱敏）

`RecordExecutor` 在起始页就绪后采集：

- 同源 JSON 请求摘要（最多 30 条，单条 preview ≤ 2KB）

### 1.3 Anthropic 兼容模型层

配置（控制面进程环境变量，**不要写入仓库**）：

| 变量 | 说明 |
| --- | --- |
| `ANTHROPIC_BASE_URL` | 网关根地址，如 `http://10.18.128.200:18080` |
| `ANTHROPIC_AUTH_TOKEN` | Bearer token |
| `ANTHROPIC_MODEL` | 模型名，如 `ark-code-latest` |
| `ANTHROPIC_TIMEOUT_SECONDS` | 默认 30 |
| `ANTHROPIC_MAX_TOKENS` | 默认 4096 |
| `ANTHROPIC_MAX_RETRIES` | 默认 2 |
| `ATP_AI_VISION_ENABLED` | 默认 false；true 时才把录制结束截图送给模型 |

代码：`apps/control-plane/autotest_control/ai/`。

模型输出契约：

- 只能按 `source_id` 修改 `label` / `phase` / `mutating` / `value`
- 不能改 `action` / `target` / 步骤顺序
- 可追加断言，target 只能引用已有步骤 id
- value/expected 模板白名单：`unique` / `now` / `env`

自测：

```powershell
python scripts\selftest_ai_compiler.py
```

### 1.4 编译—验证状态机

表：`recording_compilation`（`apps/control-plane/autotest_control/models.py`）

状态：`queued → compiling → validating → passed | manual_validation | fallback | error`

后台协调器：`apps/control-plane/autotest_control/compilation_worker.py`

- 最多 3 轮：模型编译 → 无头回放验证 → 失败则带 `previous_failure` 重编译
- 3 轮仍失败，或模型不可用 → 回退 P1.1 确定性步骤
- 站点 `env` 不是 `test/dev/development` 时，编译完成后停在 `manual_validation`，不自动写数据

API：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/v1/recordings` | 必填 `intent` |
| POST | `/api/v1/recordings/{run_id}/compile` | 启动 AI 编译 |
| GET | `/api/v1/recordings/{run_id}/compilation` | 轮询编译/验证状态 |
| POST | `/api/v1/recordings/{run_id}/compilation/retry` | 人工重试 |
| POST | `/api/v1/recordings/{run_id}/compilation/use-fallback` | 强制采用确定性步骤 |
| POST | `/api/v1/recordings/{run_id}/save` | 默认只允许保存已验证版本；`allow_unverified=true` 可存 draft |

自测：

```powershell
python scripts\selftest_compilation_worker.py
```

### 1.5 控制台

`static/index.html` 录制流程：

1. 填写「录制意图」→ 开始录制
2. 录制结束后自动提交 AI 编译
3. 展示编译/验证进度、token usage、失败原因
4. 确认页可改 label / phase / mutating / value / expected，参数化高亮
5. 未通过自动验证时，保存需二次确认

## 3. 验收标准

按顺序验：

1. `python scripts\selftest_variables.py`
2. `python scripts\selftest_ai_compiler.py`
3. `python scripts\selftest_compilation_worker.py`
4. `python scripts\selftest_compiler.py`（P1.1 清洗不回退）
5. **端到端**（需配置网关 + 开窗执行器 + 测试站点）：
   - 填意图 → 录制「新增款式」→ AI 编译通过 → 保存 → 再次回放通过
   - 编码类字段被参数化为 `{{unique:...}}`，第二次回放不撞唯一性
   - 关闭网关或故意让验证失败 → 仍能回退 P1.1 步骤并手工保存 draft

第 5 条是真正的验收：**AI 说理解了不算，回放通过才算**。

## 4. 排障

| 现象 | 对策 |
| --- | --- |
| 一直停在「AI 编译排队中」 | 控制面是否重启过；`compilation_worker` 是否在跑 |
| `ai_configuration_missing` | 检查 `ANTHROPIC_*` 环境变量；未配置时会回退确定性步骤 |
| 验证 run 一直 queued | 执行器是否在线；验证 run 不需要 headed |
| 保存报「未通过自动回放验证」 | 人工改步骤后需确认以 draft 保存，或重新编译 |
| 改代码行为不变 | 控制面与执行器都是常驻进程，改完必须重启 |
